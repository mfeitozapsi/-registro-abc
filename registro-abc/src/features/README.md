# features/

Reservada para as funcionalidades das próximas etapas. Cada uma ganhará
sua própria pasta, por exemplo:

- `registros/` – formulário de registro ABC (estrutura pronta; salvamento futuro)
- `historico/` – consultar registros anteriores
- `exportacao/` – exportar registros
- `autenticacao/` – acesso individual por usuário
- `familias/` – separação dos dados por família

Nada disso está implementado na Etapa 1.
